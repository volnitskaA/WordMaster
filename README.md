## Назва проєкту

WordMaster

## Опис проєкту

WordMaster — статичний веб-додаток для вивчення іноземних слів. Додаток містить сторінки входу, реєстрації, профілю користувача, інформацію про додаток та сторінку словника.

## Технології

* HTML5
* CSS3
* Bootstrap 5
